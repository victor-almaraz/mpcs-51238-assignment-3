# Repo structure

## Layout
```
mpcs-51238-assignment-3/
  package.json              # scripts and pinned dependencies (pnpm)
  pnpm-workspace.yaml       # pnpm store, cache and overrides; stores under .tools/
  next.config.mjs           # static export; dev server reads vercel.json rewrites and headers
  vercel.json               # /projects/<id> rewrites to the editor shell; /worklets/ no-cache

    app/                    # Next.js App Router routes

      nav/                  # site header, skip link
      pianoroll/            # piano-roll canvas, grid mirror, velocity lane, commands

      ui/                   # shared controls: buttons, toggles, knob, fader, slider, meter, menus, dialog, tooltips
```

Generated and local-only directories are git-ignored: `.tools/` (Node, pnpm store and cache, Playwright browsers), `node_modules/`, `.next/`, `out/`, `public/worklets/`, `test-results/`, `playwright-report/`.

## Build rules
| Rule | Value |
|---|---|
| Language | JavaScript (ES2022 modules, `.js` and `.jsx`); `@/` resolves to `src/` |
| Output | `pnpm build` writes a static export to `out/` (`output: 'export'`) |
| Editor route | `/projects/[id]` prerenders one shell page, `_shell`; `vercel.json` rewrites every `/projects/<id>` to it, and the loader reads the ID from the address |
| Worklet and worker modules | `scripts/copy-worklets.mjs` copies `src/dsp`, `src/worklet` and `src/workers` to `public/worklets/` before `dev` and `build`; they load by plain URL (`/worklets/worklet/main.js`, `/worklets/workers/peaks.js`) |
| Worklet caching | `/worklets/` is served with `Cache-Control: no-cache` |
| Audio-thread code | `src/dsp` uses no host globals and imports only from `src/dsp` (ESLint) |

## Development server
- `pnpm dev` copies the worklet sources, watches them for changes and runs `next dev`.
- The development server applies the `vercel.json` rewrites and headers through `next.config.mjs`.

## Commands
| Command | Purpose |
|---|---|
| `pnpm dev` | Development server with worklet copy and watch |
| `pnpm build` | Static export to `out/` |
| `pnpm start` | Serves `out/` with the `vercel.json` rewrites and headers on port 3100 |
| `pnpm lint` | ESLint |
| `pnpm test:dsp` | Unit tests (`tests/dsp`) |
| `pnpm e2e:install` | Installs Chromium, Firefox and WebKit into `.tools/ms-playwright` |
| `pnpm test:e2e` | End-to-end tests against `out/`, or against `BASE_URL` when set |

Every command runs with `PATH=$PWD/.tools/node/bin:$PATH`.
