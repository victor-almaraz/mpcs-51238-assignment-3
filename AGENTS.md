# AGENTS.md

## Project Description

This project implements a basic web digital audio workstation. The DAW supports audio and MIDI tracks, MIDI instruments, and audio effects. The synthesizers from the previous assignment are reworked here as MIDI instruments. The web application will be presented using the same design system as the synthesizer rack from the aforementioned assignment.

## Project Constraints

This project may only use HTML, CSS, Javascript, Next.js, and Tailwind. No other Javascript frameworks, external APIS, or databases may be used. The site must be a static page, where all functionality is accomplished through the user's browser.

No agent may edit this file or `README.md`.

## Project Documentation

All project documentation can by found in the `doc\` directory. Documentation covers the project design, project implementation plan, audio processing, audio safety, synthesis types, MIDI standards, and IO. Agents should first refer to the relevant documents before writing or editing code. Copies of the documentation in context are sufficient unless otherwise specified by the user.
